Modern Web Crawler & SEO Audit Tool with Graphical Interface

⚙️ Installation Guide & Dependencies

To run this script smoothly, ensure you have Python installed on your system. Most required modules are part of Python's standard library, but two external packages are strictly necessary.

1. Python Standard Libraries (Built-in):

The script automatically relies on the following standard modules which require no manual installation:

  • urllib, time, json, ssl, sys, re, os, csv, math, threading: Core modules for network, parsing, threading, and file management.
  • tkinter: Standard Python interface for graphical elements (ensure your Python installation includes Tcl/Tk, which is standard on Windows/macOS and available via package managers on Linux like sudo apt install python3-tk).

2. External Dependencies Installation:

You need to install httpx (for HTTP requests) and beautifulsoup4 (for HTML parsing). Run the following command in your terminal:

pip install httpx beautifulsoup4

3. Running the Script:

python your_script_name.py

🚀 Key Features

Multi-threaded Crawler

Asynchronous crawling logic running in a background thread to keep the user interface fully responsive.

SEO Data Extraction

Collects page titles, meta descriptions, H1/H2/H3 tags, crawl depths, outbound and inbound link counts.

Interactive Dashboard

Built-in table viewer, visual charts for HTTP status distribution and page depth levels.

Auto-Save & Export

Automatically saves preferences directly into the source code and allows exporting audit data to CSV or JSON.

📖 How to Use

  • Configuration Tab: Enter your target URL, set the maximum number of pages, apply optional filters, select a User-Agent, and choose your output file name. Click Run Audit to start.
  • Control Controls: Use the Pause or Stop buttons anytime during the crawl process to manage execution.
  • Table Viewer Tab: Load any previously generated JSON audit file to inspect data or export results directly to a CSV file.
  • Charts & Stats Tab: Analyze visual breakdowns of server response codes (HTTP status) and structural site depth.
  • Raw JSON Viewer Tab: Open and view formatted, clean raw JSON structures of your audit reports.
